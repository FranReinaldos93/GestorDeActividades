# Gestor de Actividades

Proyecto del modulo desarrollo de interfaces de 2º DAM, actualmente en desarrollo

## 🛠️ Tecnologías
- Java
- JavaFx
- PostgreSQL
- NetBeans
- SceneBuilder

## ▶️ Cómo ejecutarlo
1. Clona el repositorio: `git clone https://github.com/TU-USUARIO/TU-REPO.git`
2. Abre el proyecto en NetBeans.
3. Configura la conexión a PostgreSQL (usuario, contraseña y nombre de la base de datos).
4. Ejecuta el proyecto.
